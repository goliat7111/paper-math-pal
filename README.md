# Matematikapp för utskrifter

Skapa en lärarapp där läraren kan generera och skriva ut anpassade arbetsblad och diagnoser i matematik på A4 (även med facit).
Utgå från de bifogade Excel-filerna och börja med två flikar/övningstyper från del 2:
1. 102 tal (5min) - multiplikationsdiagnos med anpassningsbara intervall för faktor 1 och faktor 2 (standard 2-9 och 3-9), slumpade uppgifter, fält för namn, datum och poäng (av 102).
2. Mult.uppst (1-talsfaktor) (få) - multiplikationsuppställning med 1-talsfaktor med rutnätslayout för uppställning och minnessiffror, anpassningsbara faktorer (standard 2 till 9), samt generering av ny slumpad variant och utskriftsoptimerad A4-vy.
